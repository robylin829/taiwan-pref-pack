# 台灣裝得下！ Taiwan Pref Pack

一款以台灣 22 縣市為主角的物理掉落合體遊戲。移動、落下，讓接壤或相鄰的縣市碰撞合體，最後把五個地方拼成完整台灣。

線上遊玩：**https://robylin829.github.io/taiwan-pref-pack/**

推送到 `main` 後，GitHub Actions 會先執行測試與建置，再自動部署至 GitHub Pages。Pull request 只執行檢查。

玩法靈感來自 [Dopamine Game Lab 的新・都道府県ゲーム](https://sns.dopagamelab.com/pref-pack/)。本專案的介面、程式與台灣內容重新實作，未使用原站程式、音樂或美術素材，亦非官方作品。

## 執行

需要 Node.js 20 或更新版本。遊戲所需物理引擎已放在 `vendor/`，不用安裝套件就能開啟：

```sh
node scripts/serve.mjs
```

瀏覽 `http://127.0.0.1:5173`。請透過 HTTP 伺服器開啟，勿直接雙擊 HTML。

```sh
npm ci
npm test
npm run build
```

建置結果在 `dist/`，可放到 GitHub Pages、Cloudflare Pages、Netlify 等靜態網站服務；部署目錄設為 `dist`。所有資源使用相對路徑，支援 GitHub Pages 的子目錄網址。需要重新產生地圖與第三方程式庫時，執行 `node scripts/prepare.mjs`。

## 玩法

- 滑鼠左右移動後點擊；手機拖曳定位後放開落下。
- 鍵盤 `←` / `→` 移動、`Space` 落下、`R` 旋轉、`S` 搖一搖、`P` / `Esc` 暫停。
- 接壤或相鄰、沒有重複縣市的圖塊可以合體。跨北、中、南、東分區同樣可合體。遊戲海上連接為澎湖與高雄、連江與基隆，三離島也可互相合體。
- 所有圖塊依相鄰關係繼續合體；收齊 22 縣市獲勝。每個縣市每局只投放一次；全部投完後仍可搖一搖繼續合併，不會再補發縣市。
- 搖一搖不限次數，每次連續左右推動圖塊（間隔 0.65 秒即可再次使用）。圖塊超出虛線且穩定停留 2.5 秒就結束；新生圖塊有 2 秒緩衝。
- 每次落下 +5 分，合體加「合體後縣市數 ×15」；每個完整地方額外 +100，完整台灣再 +1000。
- 自動保存當前旅程與本機前三名成績，可暫停、續玩、重新開始與分享成績。無帳號、無後端、無追蹤。

## 五大地方

| 地方 | 縣市 |
| --- | --- |
| 北部地方 | 臺北市、新北市、基隆市、桃園市、新竹縣、新竹市、宜蘭縣 |
| 東部地方 | 花蓮縣、臺東縣 |
| 中部地方 | 苗栗縣、臺中市、彰化縣、南投縣、雲林縣 |
| 南部地方 | 嘉義縣、嘉義市、臺南市、高雄市、屏東縣 |
| 離島地方 | 澎湖縣、金門縣、連江縣 |

分區採本遊戲設定。綠島、蘭嶼隸屬臺東縣；離島地圖使用示意位置。遊戲圖塊取各縣市最大陸塊的簡化真實邊界，單一圖塊縮放以維持可玩性，單一縣市最長邊為 84 遊戲單位，合體後縮成原圖塊合計面積的約 52%，以騰出空間；碰撞範圍使用內縮 10% 的輪廓凸包，降低摩擦讓圖塊更容易滑入空隙，地理鄰接依來源 TopoJSON 共用邊界判定。

## 技術與資料

原生 HTML / CSS / JavaScript、Canvas、Matter.js；不需要框架或建置工具。可在無網路環境遊玩，外部 Google Fonts 無法載入時會使用系統字型。

地圖來自 [Taiwan.md 台灣的形狀](https://taiwan.md/taiwan-shape/)，原始資料為 Waiting 的 `taiwan-vue-components`（MIT，2018）。完整來源與授權見 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。

測試涵蓋縣市完整性、區內地理連通性、合法與非法合體、五區完成台灣、隨機袋與物理碰撞。

綠色虛線標示目前待投放縣市能合併的鄰居，旋轉可以幫助放入空隙。舊版存檔續玩時會自動去除重複縣市並整理剩餘投放順序。
